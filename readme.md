## ✨ Features

| Feature | Description |
|---------|-------------|
| 💬 **Real-time AI Chat** | Send prompts and receive intelligent responses from Gemini |
| 📜 **Recent Chats** | View and revisit your previous prompts |
| 🆕 **New Chat** | Start a fresh conversation anytime |
| 📱 **Responsive UI** | Clean, animated layout inspired by Gemini |
| ⌨️ **Streaming Text** | Smooth word-by-word text reveal effect |
| 💡 **Prompt Suggestions** | Quick suggestions to get started |
| 🔄 **State Management** | Context API for managing global state |
| 🎨 **Modern Theme** | Professional look with subtle animations |

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1️⃣ **Clone the repository**
```bash
git clone https://github.com/Sahil-2005/gemini-clone.git
cd gemini-clone
```

2️⃣ **Install dependencies**
```bash
npm install
```

3️⃣ **Start the development server**
```bash
npm run dev
```

4️⃣ **Open your browser**
```
🌐 http://localhost:5173
```

## 🔐 API Configuration

> ⚠️ **Security Note**

This project uses the `@google/generative-ai` package with an API key.

| Environment | Recommendation |
|-------------|----------------|
| 🧪 Development | Current setup works fine |
| 🚀 Production | Use `.env` file for API key |

```env
VITE_GEMINI_API_KEY=your_api_key_here
```
